# HTML 输出

用户要 HTML 或同时要 HTML 和 Markdown 时阅读。视频来源与内容仍以同一份经核验的课程笔记为依据，不因转换丢失题目、公式、截图、引用、来源或时间索引。HTML 是可直接用浏览器阅读的文件，而不是部署网站。

## 生成

1. 用用户指定目录和主题命名 `.html`，与 Markdown 同名便于对应；若有同名文件，检查后保留用户已有内容。仅 HTML 请求允许先在工作目录形成 Markdown 中间稿，不强制多交一个 Markdown。
2. 生成完整 `<!doctype html>`、`<html lang="zh-CN">`、UTF-8、viewport、`<title>` 的 HTML，内置 CSS，适合手机与桌面阅读。使用语义化标题、段落、表格、列表、代码块和明确的导航；代码横向滚动，长链接可换行，图片自适应。配色、排版保持克制易读；用户指定样式优先。
3. 保留文章标题、正文结构、来源及可点击视频时间索引。生成真实且唯一的标题 id，目录片段链接逐一对应；链接必须使用原笔记的真实 URL/时间，不得猜造。保留所有实质内容与练习答案，代码按文字转义后放 `pre/code`，不能将视频字幕当脚本执行。对源文字或不受信任的 HTML 转义或清理，避免带入可执行脚本、事件处理器或危险链接；仅加入实现明确功能所需、可信的静态资源。
4. 优先输出单文件 HTML：将本地截图嵌入为数据 URL，或在用户同意的文件布局中使用相对路径并同时交付图片。不得静默依赖不存在的附件；外部来源图片不可访问时标记。截图须清晰且与上下文一致。
5. 数学公式不能退化为无法理解的源码或丢失：用可用的可信本地数学渲染器输出静态 MathML/SVG，或在用户允许联网时使用可信 MathJax/KaTeX 运行时并保留数学定界符。若只能调用远程库，交付时明确说明联网要求；无可用渲染方案时保留可见公式源码并如实说明，禁止声称离线公式已渲染。图表同理：Mermaid 尽量导出静态 SVG；不能渲染时保留可读的代码并说明，不伪称图已显示。不要未经用户要求把 HTML 发布到网络。

## 检查

用可用的浏览器或渲染工具打开最终 HTML，在桌面和窄屏检查标题层次、换行、代码、表格、图片及时间索引；检查所有目录锚点和相对文件，点击代表性视频跳转链接。核对数学公式和图表实际显示；有远程依赖时说明是否在联网条件下验证。与经核验的 Markdown 逐节比对，确保没有漏内容或增加无法追溯的事实。如果无法预览或确认某项功能，明确告知，不声称已经通过。最终交付用户要求的文件链接，并说明依赖或缺失资源。
